1. Overview

L&B Global is a CRM and content management system for an overseas education consultancy. It supports the full student journey from inquiry submission through to enrollment, including internal staff collaboration, document management, contracts, invoices, and a public newsletter/CMS.

Key principles:

  • No student logins: Students (applicants) only submit inquiries via the public Apply form. There is no student dashboard or student authentication.
  • Staff-only dashboards: Admin, Sub-Admin (Agent), and Internal Staff (Case Manager) log in and manage submissions, profiles, tasks, and communication.
  • Role-based access: Each role has a dedicated dashboard and permissions aligned with their responsibilities.

2. User Roles & Permissions

Role Label Dashboard Path Permissions
ADMIN Admin /dashboard/admin Full access: staff CRUD, analytics, students, newsletter posts, templates, questionnaire config, communication. Can create/edit/delete Admin, Sub-Admin, and Internal Staff accounts.
SUB_ADMIN Agent /dashboard/sub-admin Assigned and unassigned submissions; team members; own newsletter posts; communication; delegate students to Internal Staff; bulk status updates.
INTERNAL_STAFF Case Manager /dashboard/internal-staff Only assigned students; tasks; documents (bulk verify); communication; no admin/analytics access.
USER Applicant N/A (no dashboard) Cannot log in. Submits inquiries only via the public /apply form.

Auth rule: USER role cannot sign in. Only ADMIN, SUB_ADMIN, and INTERNAL_STAFF may authenticate.

3. Complete Workflow

3.1 Student Inquiry Submission

  1. Applicant visits the public /apply page.
  2. Form fields are driven by the active QuestionnaireTemplate plus built-in fields.
  3. Required fields: Full name, Email, Country (from prioritized list), Where did you hear from us?.
  4. Where did you hear from us? options: Higher Perspective, Google Search, Facebook, Instagram, TikTok, Friends/Family, Existing Student, Education Fair, Others.
  5. If Others is selected, the Additional note field becomes mandatory.
  6. Submission creates or updates User (role USER), StudentProfile, and QuestionnaireSubmission.
  7. Staff email addresses cannot submit; validation blocks them.
  8. Confirmation email is queued via the email outbox.
  9. Submission status: SUBMITTED.

3.2 Staff Handling (Admin / Sub-Admin)

  1. Admin can assign submissions to Sub-Admins.
  2. Sub-Admins claim unassigned cases or receive assigned ones.
  3. Status progression: SUBMITTED → UNDER_REVIEW → DOCS_REQUESTED → OFFER_RECEIVED → VISA_GRANTED → REJECTED or ENROLLED.
  4. Students can be delegated to Internal Staff via StudentAssignment.
  5. CSV export of submissions is available (Admin and Sub-Admin).

3.3 Student Profile Management

Created automatically when the first submission is made. Extended with:

  • Visa status, course dates, visa expiry, follow-up dates
  • Documents (upload, verify, bulk verify)
  • Tasks (create, assign, track)
  • Contracts and Invoices
  • Communication threads (student-related)

Access control: Sub-Admin sees assigned and unassigned students; Internal Staff sees only assigned students.

3.4 Documents & Verification

  • Categories: PASSPORT, TRANSCRIPT, SOP, OFFER_LETTER, VISA, FINANCIAL, IDENTITY, OTHER.
  • Verification: PENDING → VERIFIED or REJECTED.
  • Internal Staff can bulk verify documents.

3.5 Contracts

  • Statuses: DRAFT, SENT, ACCEPTED, REJECTED, CANCELLED.
  • Built from EmailTemplate (type CONTRACT) with placeholders like {{studentName}}.
  • Rendered via template-renderer.

3.6 Invoices

  • Statuses: DRAFT, SENT, PAID, OVERDUE, CANCELLED.
  • Uses InvoiceLineItem for line items.
  • Totals calculated via invoice-calculator.

5. Dashboard Structure by Role

Admin (/dashboard/admin)

  • Overview: Executive Snapshot, Admin Command Center, Reminders
  • Students: Priority categories, filters, CSV export, assign to Sub-Admin, delegate to Internal Staff
  • Analytics: Charts, lead source summary, country/course/intake
  • Staff & Content: Questionnaire config, templates, communication, newsletter posts, Admin/Sub-Admin/Internal Staff CRUD, job titles, team assignments

Sub-Admin (/dashboard/sub-admin)

  • Overview: Manager Analytics, Risk Board, SLA Breach Alerts, Reminders
  • Students: Assigned students; filters (all, unassigned, overdue, needs_approval); bulk status update; delegation
  • Team & Operations: Approval queue, assignment board, newsletter posts, Weekly Manager Report (CSV)

Internal Staff (/dashboard/internal-staff)

  • Overview: Active cases, open tasks, overdue, pending docs
  • Work Queue: Priority queue, follow-ups, deadlines
  • Tasks & Docs: Tasks, bulk document verification
  • Students: Assigned students only, communication threads

6. Authentication & Middleware

Login

  • Credentials (email + password)
  • USER role rejected
  • Session with JWT; id and role in token
  • Redirect to /dashboard → getDashboardPath(role)

Forgot / Reset Password

  • Forgot: /forgot-password → VerificationToken
  • Reset: /reset-password (token from query)

9. Cron Jobs & Integrations

Cron

  • Path: /api/cron/reminders
  • Schedule: 0 9 * * * (9:00 AM daily)
  • Auth: CRON_SECRET Bearer token
  • Action: Builds reminders per staff user, sends digest via email outbox
